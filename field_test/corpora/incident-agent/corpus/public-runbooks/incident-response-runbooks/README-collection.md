# About this collection

Ten runbooks covering the most common incident types for a modern cloud-and-SaaS environment. Each follows the same skeleton, Trigger, Immediate, Investigation, Containment, Eradication, Recovery, Post-incident, Reference data to capture, so responders can move between them without retraining.

## Index

1. Leaked AWS Access Keys
2. Public S3 Bucket Exposure
3. Ransomware on Endpoint or Server
4. Account Takeover
5. Supply Chain Compromise
6. Insider Threat
7. DDoS Attack
8. Data Exfiltration
9. Malware on Endpoint
10. Third-Party / Vendor Breach

## How to use

Pick the runbook that matches the trigger. Work top to bottom but expect to loop between Investigation and Containment as new findings emerge. The Reference data to capture section feeds your post-incident report and any regulatory filing.

These are starting points, not substitutes for judgment. Real incidents have details these documents don't anticipate. Adapt freely.
